# Ramudu's Express — Commercial Website Starter

Responsive commercial-style website for Ramudu's Express.

## Run locally
1. Open this folder in VS Code.
2. Install Live Server.
3. Open `index.html` and click **Go Live**.
4. Browse the localhost address in Edge, Firefox, Safari, Chrome, or another modern browser.

The `.vscode/settings.json` file prevents Live Server from opening a browser automatically.

## Publish free
Upload the entire project folder to a static host such as Netlify. Keep `index.html` at the project root and preserve `css/`, `js/`, and `assets/`.

## Commercial production note
The demo booking form uses localStorage and WhatsApp. Before accepting real customer data, connect authentication and bookings to a hosted database such as Supabase and implement server-side admin authorization and Row Level Security.
